## How to regenerate

```sh
# From the repo root — fill in SUPABASE_SERVICE_ROLE_KEY in .env first
bash scripts/seed-test-users.sh
```

The script is idempotent. Re-running it detects existing users by email (via the Auth Admin API list endpoint), skips them, and re-applies all DB row upserts with `Prefer: resolution=ignore-duplicates`. It will not create duplicate rows or duplicate users.

- These credentials are hard-coded in this doc and in the seed script. They are for the dev/QA project `seicofzlgwjqkggscvao` only.
